# ММТ Онлайн

Проект приложения для подготовки выпускников 11-го класса к ЦВЭ/ММТ.

## Источник проекта

Полный исходный Android-проект и офлайн-каталог лежат в архиве [mmt-online-source.zip](mmt-online-source.zip). Архив включает Android WebView app, официальный план специальностей НЦТ 2026–2027 и структуру экзамена.

## Сборка тестового APK

1. Открой вкладку **Actions**.
2. Выбери **Build Android APK** и нажми **Run workflow**.
3. После завершения скачай артефакт `mmt-online-debug-apk` из запуска workflow.

APK пока является прототипом выбора специальностей. Тренировки, полный банк оригинальных вопросов, пробный экзамен и экран прогресса ещё разрабатываются. Тестовые материалы НЦТ не копировались.
