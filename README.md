# ММТ Онлайн — приложение для выпускников 11-го класса

Офлайн-приложение для подготовки к ММТ в Таджикистане. Интерфейс на русском и таджикском языках.

## Скачать APK

Открой **Actions → Build Android APK**, выбери последний успешный запуск и скачай артефакт `mmt-online-debug-apk`. APK устанавливается вручную на Android. Для Google Play потребуется отдельная подписанная сборка AAB.

## Функции прототипа

- пять кластеров ММТ и подбор до 12 специальностей;
- поиск по специальности, коду, учебному заведению и городу;
- 5 121 вариант из плана приёма НЦТ 2026–2027;
- тренировки по предметам, короткий пробный тест на 40 заданий с таймером;
- тесты с выбором ответа, открытым ответом и соответствиями;
- разбор ошибок, сохранение статистики и серии дней офлайн.

Внутри архива проекта `mmt-online-source.zip` лежит исходный Android-проект.

**Важно:** тестовый набор содержит демонстрационные оригинальные задания, а не официальные варианты НЦТ. Короткий пробный тест предназначен для проверки приложения и не является точной копией экзамена.
